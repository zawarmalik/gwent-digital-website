# Gwent Digital — website

Marketing site for Gwent Digital (gwentdigital.co.uk), built with Next.js 16 App Router.

Built against the [v2 PRD](../..) — see `AGENTS.md`/`CLAUDE.md` for framework-specific agent
notes generated by Next.js itself.

## Status

**Phase 1 (foundation)** — homepage, contact form, legal pages, deployed. Case studies,
department detail pages, `/solutions`, and `/pricing` are Phase 2 and depend on real content
the owner still needs to supply (see the PRD's §19 outstanding items — company number,
registered address, pricing figures, case study permissions, logo, solution catalogue).

The previous static HTML site has been kept at [`legacy-static/`](./legacy-static) rather than
deleted.

## Stack

- Next.js 16, App Router, TypeScript strict
- Tailwind CSS v4, tokens in `src/app/globals.css` (estuary/oxide palette, PRD §5.4)
- shadcn/ui (Radix primitives) restyled to tokens
- React Hook Form + Zod for the contact form
- Resend for contact form email delivery

## Setup

```bash
npm install
cp .env.example .env.local   # fill in RESEND_API_KEY
npm run dev
```

## Environment variables

See `.env.example`. `RESEND_API_KEY` is required for the contact form to actually send email —
without it, the form fails gracefully and tells the visitor to email hello@gwentdigital.co.uk
directly.

## Content authoring

There's no CMS yet. Copy lives directly in the component files under `src/components/home/`.
Department data is in `src/lib/departments.ts`. When `/work`, `/solutions`, and `/pricing` are
built in Phase 2, follow the PRD's MDX content model (§8.5 build note) so the owner can add
entries without touching components.

## Deployment

Hosted on Vercel, project `gwent-digital`. Push to `main` for production, or open a PR for a
preview deployment.
